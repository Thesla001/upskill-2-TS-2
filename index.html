Search

Action attribute: It specifies where the form data should be sent when the form is submitted.
Method attribute: it specifies how the form data should be submitted such as using GET or POST.
GET: GET is commonly used because the search information can be included in the URL, making it easy to see bookmark, or share the search.
POST: POST can be used to send Registration information in the request body rather than putting the submitted values directly in the URL.
Using post does not automatically make information secure. Security also requires measures such as HTTPS and proper server-side security practice.
